## AgentCodeGUI 3.2.3

설정에서 ChatGPT와 Claude의 구독 갱신일과 취소 예정일을 함께 확인할 수 있습니다. 계정별로 웹 로그인을 연결하고, 마지막으로 확인한 구독 정보를 보관합니다.

- **계정 카드에서 갱신일과 종료일 확인** — 설정 → Account의 각 계정에서 웹 연결을 하면 자동 갱신, 취소 예정, 구독 종료 등의 상태와 날짜를 표시합니다. ChatGPT는 웹 연결 전에도 로그인 정보에 있는 구독 기간을 확인할 수 있습니다.
- **필요할 때 구독 정보 새로고침** — 연결된 계정은 설정을 열 때 6시간 이상 지난 정보를 순서대로 갱신합니다. 새로고침으로 즉시 확인하거나 진행 중인 연결·조회를 취소할 수 있습니다. 조회가 끝나면 보조 브라우저를 종료합니다.
- **로그인이 만료돼도 마지막 정보 유지** — 웹 로그인이 만료되거나 조회가 실패해도 마지막으로 확인한 날짜와 상태를 남깁니다. 확인 날짜와 다시 연결 안내를 표시하고, 재연결에 성공하면 최신 정보로 바꿉니다.
- **계정별 연결 관리** — 다른 계정으로 로그인한 경우 안내를 표시하며 해당 구독 정보를 섞어 저장하지 않습니다. 연결 해제는 선택한 계정의 웹 연결과 저장 정보를 지웁니다. 웹 연결 해제는 구독 취소가 아닙니다.

웹 연결에는 Chrome 또는 Edge가 필요하며, 웹 로그인 상태에 따라 재연결이 필요할 수 있습니다.

## AgentCodeGUI 3.2.3 (English)

Check ChatGPT and Claude subscription renewal and cancellation dates in Settings. Connect each web account and keep its last confirmed subscription details.

- **Renewal and end dates on account cards** — Use Connect web account in Settings → Account to see renewal, scheduled cancellation, and subscription end dates. ChatGPT can also show the subscription period from saved sign-in information before a web account is connected.
- **Update subscription details when needed** — Opening Settings refreshes connected accounts whose details are at least six hours old, one at a time. Refresh checks immediately, and pending connections or checks can be cancelled. The helper browser closes when the check finishes.
- **Keep the last details after sign-in expires** — If web sign-in expires or a check fails, the last confirmed date and status stay visible with the check date and a reconnect prompt. A successful reconnection replaces them with current details.
- **Manage each connection separately** — Signing in to a different account displays a notice instead of saving its subscription to the selected account. Disconnect removes only that account’s web connection and saved details. Disconnecting does not cancel a subscription.

Web connections require Chrome or Edge. You may need to reconnect when your web sign-in expires.

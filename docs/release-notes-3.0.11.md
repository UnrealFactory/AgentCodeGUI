## AgentCodeGUI 3.0.11

사이드바와 파일 뷰어의 반응을 개선하고, Codex 작업 표시와 툴팁을 수정했습니다.

- **자동 펼침 반응 개선** — 자동 모드에서 마우스를 가까이 가져갈 때 불필요한 화면 갱신을 줄였습니다.
- **파일 뷰어를 더 빠르게** — 본문 표시를 늦추던 대기를 제거하고, 뷰어 사전 준비와 읽기 모드 색상 정보 재사용으로 파일을 처음 열거나 다시 열 때의 지연을 줄였습니다.
- **작업 중 문구가 바로 표시** — Codex의 중간 답변 뒤 작업 문구가 30초~1분 동안 사라지던 문제를 수정했습니다.
- **속도 설명도 앱 툴팁으로** — 표준·Fast 등의 속도 설명에 앱 툴팁을 적용했습니다. 메뉴 밖으로 잘리지 않으며 키보드 포커스도 지원합니다.

## AgentCodeGUI 3.0.11 (English)

Improves sidebar and file viewer responsiveness, and fixes Codex activity indicators and tooltips.

- **Smoother automatic reveal** — Reduced unnecessary screen updates when the pointer approaches the sidebar.
- **Faster file previews** — Removed the wait before showing content. Prepares the viewer ahead of time and reuses syntax colors in read mode to reduce first-open and reopen delays.
- **Immediate activity feedback** — Fixed the 30–60 second gap in the working indicator after an intermediate Codex reply.
- **App tooltips for speed options** — Standard, Fast and other speed descriptions use the app tooltip style, escape menu clipping and support keyboard focus.

R2 주석 — §2.2-4·§2.2-5
감시자가 Rust로 갔다(U1). 2.6.2는 useTurnNotifyList가 항목마다 state: SessionState를 요구했다(notify.ts:34) — 마커엔 스냅샷이 없으니 "접힘도 감시"와 "접힌 자리는 마커"가 정면 충돌했다. 3.0은 ChatRuntime이 뷰 없이도 살아 있어 스냅샷 없이 전이를 판정한다.
감시 집합 = ChatRuntime이 사는 모든 채팅. 자리·창·다이얼·접힘과 무관. 사이드바의 「유휴 메모리 4차 패스 측정」은 보드 slots에도 창에도 없는데 계속 돈다 — R1의 정의("보드 slots ∪ 창")는 이걸 놓쳤다(열린 문제 ③).
후퇴 없음. 2.6.2는 활성 세션 6패널(MultiAgent.tsx:891-898) + 본채팅 1 + 열린 창 각 1을 감시했고 비활성 세션 패널은 감시 밖이었다. 3.0 집합은 그 상위집합이다.
오탐 토스트도 죽는다. prev 맵이 컴포넌트 수명에 묶여 있어 감시 집합이 가변 길이가 되면 빠졌다 돌아온 채팅이 낡은 값과 비교돼 오탐이 났다. Rust는 prev를 ChatRuntime에 둔다 — 마운트/언마운트가 없다.
표시값은 ChatStatusLite에서 온다(§4.3). 사이드바 점·배지 ‼N· 완료 링·읽지 않음 수는 전부 스냅샷 없이 계산된다. 부팅 값은 chats-v3/index.json.statuses(얼려 저장 — 2.6.2 sessionChats.ts:28· maStore.ts:94의 일반화), 이후 chat:status REPLACE가 덮는다.
자동 승격 금지. 접힌 자리의 카드가 화면을 뺏지 않는다. 올리는 것은 ↥ 또는 「승인 대기」 칩 클릭 둘뿐이고, 키보드(숫자·Enter·Esc)는 focusedChatId 게이트라 보이지 않는 카드가 키를 먹지 않는다.
읽지 않음 배지는 신규다. 2.6.2엔 없다(사이드바는 상태 점뿐, styles.css:336-341). 자리가 6개면 "내가 안 본 답변"이 실제로 생긴다 — 열린 문제 ⑪로 물어본다.
노란 카드 = 목업 주석(실제 UI 아님) ‼ = 사용자 응답 대기(승인·질문). 실행 중(노란 점)과 구분되는 상태다 오른쪽 아래 접힌 자리 스트립은 선택적 표시 — 열린 문제 ②의 "얼마나 크게 알릴까" 토스트는 창이 비포커스일 때만. 판정은 main(2.6.2 규약 그대로)

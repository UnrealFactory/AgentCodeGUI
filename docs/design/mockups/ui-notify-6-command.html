설계 근거 (블라인드 판정 전에는 펼치지 말 것)

거의 안 바꾼 이유. 이 카드는 2.6.2에서 이미 제 일을 한다 — 스피너가 시각 자리를 대신하고 (styles.css:1392), 실패는 테두리·타일·배지 세 곳에 빨강을 얹는다. 체계를 만든다고 잘 되는 것을 흔들면 손해다.
바꾼 것 1 — 수치를 부제 줄로. 현행 .cmd-card-stats는 줄 하나를 통째로 쓴다 (margin-top:6px + 12px 줄). 부제가 짧아 가로로 남으므로 ·로 이어 붙인다. 긴 부제면 자연 줄바꿈되니 정보는 안 잃는다.
바꾼 것 2 — 치수 통일. 타일 32→30px, 반경 14→12px, 배지 12→11.5px, 패딩 13/15→12/14. 전부 다른 6종과 같은 값으로 맞추는 것이지 "작아 보이게" 하는 게 아니다.
바꾼 것 3 — 제목의 군말. "명령을 완료하지 못했어요" → "완료하지 못했어요". 배지가 이미 /security-review라고 말하고 있으므로 '명령'은 중복이다.
새 규약 — 중복 금지. pendingCommand가 살아 있는 턴의 오류는 카드만 말한다. 위 오른쪽 패널이 지금 일어날 수 있는 모습이다.

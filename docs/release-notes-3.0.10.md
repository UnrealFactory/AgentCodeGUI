## AgentCodeGUI 3.0.10

Clear 후 멈춤을 수정하고, Codex 도구 연동과 여러 파일의 변경 내용 확인을 개선했습니다.

- **Clear 후 첫 메시지 멈춤 수정** — Clear 직후 메시지를 보내면 생각 중에서 멈추던 문제를 수정했습니다. 취소한 뒤 다시 보내지 않아도 대화를 이어갈 수 있습니다.
- **MCP·스킬 연동** — 선택한 계정과 작업 폴더의 Codex MCP·스킬을 불러옵니다. 로컬·전역 필터와 $ 스킬 자동완성을 지원하며, 지원되는 항목의 켬·끔 설정은 계정별로 저장해 다음 실행에 반영합니다.
- **여러 파일을 펼쳐서 확인** — Edit 행을 누르면 수정한 파일 목록이 펼쳐집니다. 각 파일을 따로 열고 파일별 추가·삭제 줄 수도 확인할 수 있습니다.
- **패치노트 정리** — 3.0.7부터의 긴 설명을 핵심 변경 사항 위주로 줄였습니다. 한국어와 영어 모두 같은 내용으로 정리했습니다.

## AgentCodeGUI 3.0.10 (English)

Fixes the first message after Clear and improves Codex tools and multi-file edit review.

- **First message after Clear** — Fixed messages getting stuck on thinking immediately after Clear. Conversations now continue without cancelling and resending.
- **MCP and skills integration** — Loads Codex MCP servers and skills for the selected account and folder, with Local/Global filters and $ skill completion. Supported toggles are saved per account and applied on the next run.
- **Expand multi-file edits** — Click an Edit row to expand its file list. Open each file separately and see its added and removed line counts.
- **Shorter patch notes** — Rewrote the notes from 3.0.7 onward around the changes that matter to users, in both Korean and English.
